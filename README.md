# myint

Personal site for Phil Myint — home page and résumé.

Live site: [myint.ordoanimi.com](https://myint.ordoanimi.com/)

## Purpose

A static site introducing Phil Myint and linking to the OrdoAnimi ecosystem
properties, plus a standalone résumé page.

## Structure

This is a plain static site with no build step. The tracked files are:

| File | Purpose |
|---|---|
| `index.html` | The home page (markup, styles, content) |
| `resume.html` | Standalone résumé page |
| `robots.txt` | Crawler directives and sitemap reference |
| `sitemap.xml` | Sitemap listing the site's pages |

Deployed via Vercel from this directory — no build or install step, the
repository contents are published as-is.
