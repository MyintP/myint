# myint

Personal founder website for Phil Myint, founder of the ZenCloud ecosystem.

Live site: [myint.zencloud.com.au](https://myint.zencloud.com.au/)

## Purpose

A single-page static website introducing Phil Myint and the ZenCloud ecosystem:
ZenCloud Advisory, StudioSix AI delivery, and the ZenCloud Velocity Architecture
Framework. The page summarises the strategy, delivery, and architecture focus of
the ecosystem and links visitors to the relevant properties.

## Structure

This is a plain static site with no build step. The tracked files are:

| File | Purpose |
|---|---|
| `index.html` | The complete single-page site (markup, styles, content) |
| `CNAME` | Custom domain mapping (`myint.zencloud.com.au`) |
| `robots.txt` | Crawler directives and sitemap reference |
| `sitemap.xml` | Sitemap listing the site root |

## Deployment

Served as a static site at `myint.zencloud.com.au` from the `main` branch.
There is no build or install step — the repository contents are published as-is.
